日中IT外来語比較データベース

【概要】
日本語と中国語で使われるIT外来語を検索・比較・登録するWebサービスです。
SQLiteを使用し、単語の追加・表示・編集・削除ができます。

【実行方法】
1. Node.jsをインストールします。
2. このフォルダをターミナルで開きます。
3. npm install を実行します。
4. npm start を実行します。
5. ブラウザで http://localhost:3000 を開きます。

【主な機能】
・英語、日本語、中国語、カテゴリーからの検索
・単語情報の新規登録
・登録情報の編集
・登録情報の削除
・サービス概要と利用方法の表示

【使用技術】
HTML / CSS / JavaScript / Node.js / Express / SQLite
